# QGIS-ready GIS basemap

The build workflow now creates a QGIS-ready folder structure and project package.

## Standard layer order
1. `boundary`
2. `waterways`
3. `greenspace`
4. `landuse`
5. `roads`
6. `buildings`
7. `pois`

## Project files
- `Mehrauli_GIS_Basemap.qgs` — QGIS project template generated by the workflow.
- `styles/` — QGIS QML styles for each thematic layer.
- `data/` — GeoPackage and GeoJSON exports.

## Coordinate reference systems
- Source/display CRS: EPSG:4326.
- Metric working CRS: EPSG:32643 (WGS 84 / UTM zone 43N).
- Keep the original EPSG:4326 data as the source copy; use the projected copy for measurement and drafting.

The project is a planning base derived from OpenStreetMap and is not a cadastral or survey-accurate Ward 155 boundary.
